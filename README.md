# Rhythm90 skills — version 2

Twenty portable skills for learning and practicing Rhythm90. The library includes the original eighteen skills, revised to use real context rather than mandatory website forms, plus Study Coach and Review & Renew.

Each skill is self-contained: keep its `SKILL.md` and `references/method.md` together. Use your assistant’s supported skill installation flow, or attach both Markdown files as conversation context. No Rhythm90 API key or account is needed. Your assistant may have its own usage limits.

The instructions separate evidence, assumptions, and recommendations. Synthetic audience exercises are explicitly hypothetical and cannot validate demand. Skills do not themselves grant file access, provide persistent memory, or schedule work.

Edit skill instructions directly. `node generate-skills.cjs` refreshes the catalog; it no longer regenerates or overwrites hand-maintained instructions. The companion website packages the same release from `rhythm90-real/site/skills/`; keep both copies synchronized when publishing an update.
